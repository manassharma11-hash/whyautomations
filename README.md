# WhyAutomations reconstruction

The site is served as a static React production distribution. `vercel.json`
rewrites every route to `index.html`, letting the embedded client-side router
render the requested page.

The deployment disables ordinary page text selection while preserving normal
text entry and selection inside form fields.

The homepage hero includes a WhyAutomations-branded animated treatment.

Vercel production deployment is connected to this GitHub repository.
